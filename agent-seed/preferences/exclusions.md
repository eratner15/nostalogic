# Exclusions (read-only)

The corpus excludes franchises already in active blockbuster production. If a
search turns up news about a property that is not in the NostalDamus library,
do not propose it. You can mention it as a note only if it shows a pattern
that matters for a library property (for example, a studio buying a catalog
that includes one).

News older than 30 days is out of scope unless it is the first time you saw
it and it is an outcome (announced, released, denied) for a library property.
