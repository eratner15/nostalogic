# GLOSSARY

One word per concept. Use these words. Do not swap synonyms.

| Term | Definition |
|---|---|
| Block | The full weekly program: four slots plus connective tissue, on one fixed night. |
| Slot | One show position inside the block. There are four. |
| Anchor | Slot 1. The broadest-appeal family sitcom. |
| Hangout | Slot 2. The tween and teen ensemble comedy. |
| Wildcard | Slot 3. Sketch, variety, or odd animated comedy. |
| Lights Out | Slot 4. The mild spooky anthology. The stay-up-late reward. |
| Host | A recurring on-screen presence who links the slots. |
| Home base | The set or space where hosts appear between slots. |
| Interstitial | A short segment between slots. Hosts, games, bits, or bumpers. |
| Bumper | A very short branded transition into or out of a slot. |
| Crossover | A story or character that appears in more than one show in the same block. |
| Stunt | A one-off event that changes the block for one night. |
| Ritual | A repeated family action tied to the block: before, during, or after. |
| Ritual kit | The printable activity, snack card, and conversation prompts for one block night. |
| Premiere | The first play of a new block on the fixed night. |
| Fixed night | The single weekday on which the block premieres each week. |
| Household | One parent account and the people who watch with it. The unit of measurement. |
| Return rate | Share of households that watch a block and watch the next one. Primary metric at week 4. |
| Completion rate | Share of a household's plays that reach the end of a slot. |
| Co-viewing | A parent and a child watching the same screen at the same time. |
| Appointment viewing | Watching at a set time because the content premieres then. |
| Mechanic | A structural feature of a block that can be reused. Examples: fixed night, hosts, crossover. |
| Expression | The creative surface of a show: characters, sets, songs, logos, lines, plots. Never borrowed. |
| Canon | The confirmed facts in `canon/`. Only the Orchestrator writes canon. |
| Fork | A decision point where the Orchestrator stops and asks the owner. |
| Gate | A quality checklist that closes a phase. |
| Counsel gate | An item that needs attorney sign-off before public release. |
| Standards pass | A review by the `standards` agent that finds no failing item. |
| Made for kids | The video platform designation that disables comments, personalized ads, and most notifications. |
| COPPA | The Children's Online Privacy Protection Act, the US law on data from children under 13. |
| FAST | Free ad-supported streaming television. A linear channel delivered over the internet with ads. |
| Sponsor | A brand that pays to be part of the block. |
| Line | One franchise extension category. Examples: books, goods, music, games. |
| Window | The 1993 to 1998 span of the source nostalgia era. |
| Owner | Evan Ratner. Decides at forks. |
