Runs and reports

    How to add to this

    1. After a new run, commit its report to docs/zeitgeist/reports/, its calculator as scripts/zeitgeist/calc_<date>.py, its line in the run log, and its rows in docs/zeitgeist/history.csv.
    2. To track a project, add or edit an item in docs/zeitgeist/tracker.json. Its trend must match a board name exactly.
    3. Run python3 -I scripts/zeitgeist/build_trends.py. It recomputes every score and stops if any file disagrees.
    4. Deploy the nostalogic Worker. The page updates at cafecito-ai.com/trends.
    Every score here is recomputed from the committed calculator on each build. Nothing is typed in by hand.
