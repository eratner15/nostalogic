## Method

1. Page read. Every line of the twelve files was read for names, physical descriptions, costume constants, the one prop per character, set text, repeated lines, jokes, and the plot beats of each trailer and cold open.
2. Neighbor comparison. Each show's expression was set against the neighbors named in the title check: Long Route against School Bus (CBBC), Bus Life (Disney Channel UK), School Bus Diaries (web), and the animated window bus show; Kitchen Court against Judging Amy, Overruled!, Kids' Court, Judge Mom, and Night Court; The Returns Desk against Friday the 13th: The Series, The Haunted Museum, the window's object-driven anthology, the window's hosted campfire anthology, and the retail and hardware comedies; Recent History Society against the reenactor sketches, Sketch History, Detectorists, and the window's campfire society.
3. Window scan. Every repeated line and every character constant was checked against the well-known catchphrases, characters, props, and looks of the 1993 to 1998 family block shows a parent recalls (see the spot-check log, item 12, for the reference list).
4. Name search. Every regular's full name and every recurring name was web searched as an exact phrase with "character," and separately with "actress" or "actor," to catch a match with a real performer or a known character from any era, not only the window.
5. Likeness read. Each character sheet entry was read as an image prompt would read it, asking whether the combination of age, face, hair, costume, and prop would produce a specific real person or a specific known character.
6. Spot checks. Nineteen web searches on the elements most at risk. Logged below with result and source.
7. Distance rules. The mandatory rules from the title check were confirmed item by item against the page.

Limits. IMDb, Wikipedia, and fan wikis were reached through search excerpts only. No trademark database was reachable through the proxy. Name matches to real people rest on search results, which counsel confirms in the CG-01 pass. This check does not clear the retitled "The Returns Desk" against live marks; that stays with counsel under D-022.
