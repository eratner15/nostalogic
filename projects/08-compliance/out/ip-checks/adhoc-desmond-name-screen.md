# Ad hoc name screen: "Desmond"

Agent: compliance-gate. Date: 2026-09-19.

## Trigger

A parallel production pass, run in an external tool and not by the writers' room, put a new adult male character named "Desmond" (no surname given, 41, married) into a short adult-only sizzle-reel cut of The Returns Desk (Lights Out slot). The asset has not been through the writers' room, `standards`, or this agent's normal IP/likeness process.

## Prior fact this screen surfaced

"Desmond Nunes, 41" already exists in canon as the guest for the pilot and trailer of The Returns Desk. Source: `projects/04-writers-room/out/scripts/L1-the-returns-desk-character-sheet.md` section 6. The full name "Desmond Nunes" already cleared a name search with no exact match, logged in `projects/08-compliance/out/ip-checks/04-slate-scripts.md`, spot-check log item 19. Nothing in that character sheet states a marital status.

## Screen on the bare first name "Desmond" (no surname)

Method: web search, exact name plus "character," and separately against real, prominent people.

- Desmond Hume, a major, widely recognized character on ABC's Lost (2004 to 2010), played by Henry Ian Cusick.
- The title character of Desmond's, a UK sitcom (Channel 4, 1989 to 1994) whose lead barber is named Desmond Ambrose. The show's title is the character's first name.
- Desmond Tutu, a real, prominent, deceased public figure (archbishop, Nobel laureate). Low likeness risk absent shared traits, noted for completeness.

## Verdict

REVIEW. Not a fresh CLEAR. The cleared name on file is the full name "Desmond Nunes." Dropping the surname moves the character noticeably closer to Desmond Hume (Lost) and the title character of Desmond's, neither of which was in the comparison set that cleared "Desmond Nunes." Recommend restoring the surname "Nunes" rather than shipping "Desmond" alone, and routing the new attribute "married" through the writers' room before it becomes canon, since it is not in the current character sheet.

## Separate process flag

This asset did not originate in the writers' room and did not pass through `standards` or this agent before assembly. It also carries adult-only content against a character built for a family slot. Recommend the Orchestrator hold the asset from any release pending a normal pass, independent of the name question above.
